# ⚖️ Counselor Ahmed Mandoh - Legal Practice Website

A professional, high-end website designed and developed for **Counselor Ahmed Mandoh Law Firm**. The platform showcases legal services, consultancy areas, and professional background with a modern dark/gold aesthetic.

---

### 🌐 Live Demo
🔗 **[Visit Live Website](https://ahmed-mandoh.vercel.app/)**

---

### ✨ Features
- **Modern & Elegant Design:** Luxurious dark and gold UI crafted specifically for legal branding.
- **Fully Responsive:** Perfectly tailored for screens of all sizes (Desktops, Tablets, Mobile Phones).
- **Interactive Sections:** Hero Section, About, Legal Services, Contact, and WhatsApp integration.
- **High Performance:** Fast loading speed with clean and optimized code.

---

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling & Layout:** Flexbox, CSS Grid, Custom Animations
- **Deployment:** Vercel / Netlify
